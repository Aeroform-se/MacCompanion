Enable local playback (Speaker pairing):
To enable local playback, first you need to enable your vintage mac to act as a speaker on spotify.
You only need to do this once.
Option 1 — The easy way.
Open any official spotify app on any device that is connected to the same network as your 68k mac and select “Macintosh 68k” from the Speakers menu. Starting playback once automatically enables the speaker.
Option 2 — The manual way.
If the “Macintosh 68k” does not appear in your spotify player as a speaker, you can pair the speaker manually using the method below. This can happen if your network configuration does not allow local mDNS discovery (such as not running the docker containter in network host mode).
Click Open Spotify Speaker Login ↗ (opens in a new tab) and click Agree.
